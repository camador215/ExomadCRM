# ExomadCRM
Exomad CRM es una extensión para Microsoft Dynamics 365 Business Central que adapta el CRM a la gestión comercial de CORCs. Permite administrar oportunidades, brokers, condiciones comerciales, volúmenes, precios y cronogramas de suministro, integrando el proceso de cierre de oportunidades con la generación y gestión de documentos de venta.
